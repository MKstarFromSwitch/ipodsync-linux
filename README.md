# ipodsync-linux
Tool for syncing songs to iPod Classic, Nano, and Shuffle devices.

### How to use

First, install Git if you haven't already:
```shell
sudo apt install git
```

Then, clone the repo:
```shell
git clone https://github.com/MKstarFromSwitch/ipodsync-linux.git
cd ipodsync-linux
```

Then, make the script executable and run it:
```shell
chmod +x ipodsync-linux.sh
./ipodsync-linux.sh
```
